# docs/borrador

El documento del proyecto, por capítulos, y el mapa de qué entra en la propuesta de 4 páginas.

Va acá:
- Un archivo por capítulo, nombrado `NN-titulo.md` con número de dos dígitos.
- El mapa que traduce cada una de las 4 páginas del entregable a los documentos que la respaldan.

Regla: ningún capítulo afirma nada que no se pueda rastrear a un documento de `docs/diseno/` o a una
campaña de `mediciones/`. Si el dato no existe todavía, se escribe como pendiente y se dice de qué
ensayo depende.

La propuesta de 4 páginas no se redacta desde acá hasta que existan resultados medidos.
