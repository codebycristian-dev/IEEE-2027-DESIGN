# gestion

Control de proyecto: costo, cronograma y comunicación con los organizadores.

Va acá:
- `BOM.md` lista de materiales con costo acumulado contra el tope de US$1500 (`R7`).
- `cronograma.md` el plan de acción fechado, con compuertas de decisión.
- `preguntas-organizadores.md` las preguntas `P#`, su texto enviado y la respuesta recibida.

Regla: el costo se controla al comprar, no al final. Toda compra se registra el mismo día con su
precio real, no con el estimado.
