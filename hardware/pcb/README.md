# hardware/pcb

Esquemático y layout de la PCB de control y polarización de los diodos PIN.

Va acá:
- Proyecto del EDA completo y abrible.
- Exportaciones: esquemático PDF, Gerbers, BOM de fabricación, archivo de taladrado.
- Notas de revisión: qué cambió entre una revisión y la siguiente, y por qué.

Regla: la PCB no define el diseño, lo implementa. Si el layout obliga a cambiar un valor, se actualiza
el documento de diseño correspondiente en `docs/diseno/`, no se cambia en silencio.
